Pedir el nombre del usuario y escribirlo en la página

Este ejercicio solicita al usuario que introduzca su nombre y luego lo muestra en la página. Utiliza prompt() para solicitar la información y manipulación del DOM para mostrar el resultado.

Ejercicio 2: javascript en archivo separado

js en archivo separado e importado en el html

En este Ejercicio Práctico, deberás realizar un programa que inserte el código JavaScript a partir de un archivo separado. En este código debes emplear el método window.alert() para devolver en el explorador un cuadro de alerta con la frase “¡Hola Mundo!”.

Ejercicio 1, Leccion 2

En este Ejercicio Práctico, Haz una aplicación que calcule el área de un círculo (PI*R^2). El diámetro se pedirá al usuario para que sea ingresado a través de un cuadro de alerta en el explorador. Además, debes de emplear el Método Pow y la constante PI del objeto Math. El resultado debe entregarse por medio de un cuadro de alerta, en la consola del navegador e impreso en tu página HTML.
